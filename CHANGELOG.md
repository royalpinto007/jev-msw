# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [0.0.1] - 2026-09-21

### Added

- Contract-aware choice, noul, score, multi-answer, and dynamic Jev handlers.
- Request matching, latency, malformed responses, errors, timeouts, connection failures, rate limits, and retry sequences.
- Isolated request histories plus Vitest and Jest-compatible assertions.
- ESM, CommonJS, TypeScript declarations, source maps, Node integration, and tested examples.
