# Security policy

## Supported versions

Security fixes currently target the newest published version.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/royalpinto007/jev-msw/security/advisories/new). Do not open a public issue for a suspected vulnerability.

`jev-msw` should only intercept requests inside tests. Never put real TypeSafe API keys in fixtures, source code, logs, or bug reports.
